## 4. Relationship Between O15a and O15b

- Both tests use sample number 218m.
- Both tests use a 9.525-mm clear rod.
- Both tests use the same igniter value (-31) and flow restrictor (2).
- Both tests have a Stagnation sample distance.
- O15b is explicitly described as a reburn of the same rod used in O15a.
- These tests must not be treated as experiments on two independent samples.
- The reported extinction settings differ:
  - O15a: 0.32 pot.
  - O15b: 0.27 pot.
- The report raises possible sample heat-up effects as an explanation for the difference, but does not confirm this explanation.

## 6. Data Interpretation and Limitations

- The report footnote defines "pot" as a potentiometer reading.
- Potentiometer readings must not be interpreted as psi.
- Potentiometer readings must not be directly converted into air velocity without a verified conversion.
- The reported 5 cm/s values and potentiometer settings must be preserved as separate recorded values.
- The possible rod heat-up effect in O15b is a hypothesis raised in the report, not a confirmed conclusion.
- No visible flame in a ProofSheet image does not independently prove complete extinction.
- Smoke, residual glowing, and cooling are not confirmed by the visual review.
- Camera metadata must not be treated as experimental measurements.
- Exact extinction time must not be inferred from the ProofSheets alone.
